Python Games Collection

A collection of fun and interactive Python games.

The project currently includes:

🎯 Hangman
🎲 Dice Game
🎰 Slot Machine

A main menu allows the player to choose which game they want to play.

🕹️ Games
1. 🎯 Hangman

The computer randomly chooses a word and the player tries to guess it one letter at a time.

The game displays a Hangman drawing as the player makes incorrect guesses.

The current word list includes categories such as:

Animals
Food
Places
Technology

Example words include:

cat
elephant
pizza
chocolate
computer
keyboard
internet

The words are stored in wordslist.py.

2. 🎲 Dice Game

The Dice Game allows the player to choose how many dice they want to roll.

For example:

How many dice?: 3

The program randomly generates a number from 1 to 6 for each die and displays an ASCII representation of the dice.

It also calculates the total:

total: 12

3. 🎰 Slot Machine

The Slot Machine starts the player with a balance of $100.

The player chooses how much to bet and then spins the machine.

The available symbols are:

🍒 🍑 🍔 🍕 🏎️

Matching three symbols produces a payout.

Different symbols have different payout multipliers.

For example:

🍒 = 3x
🍑 = 4x
🍔 = 5x
🍕 = 10x
🏎️ = 20x

The player can continue playing until they run out of money or choose to stop.
